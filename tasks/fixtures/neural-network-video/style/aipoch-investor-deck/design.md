# 自包含视觉规范

## 画面与构图

本任务为竖屏视频，优先于原演示文稿的 16:9。字体和网格按竖屏阅读距离
重新安排，不机械沿用横版尺寸。四边至少留出画面宽、高各 5% 的安全区。
使用一致的对齐、宽松的留白、明确的主次和一个视觉焦点。用平面区域、
细分隔线和直接标注表达关系；分组确有语义时才使用框，不加悬浮卡片阴影。

大字陈述、简洁系统图、过程图和反馈环是可选构图方式，按所解释的关系
选择。每个画面应让人快速辨认主旨；不把原横版三列硬塞进竖屏。

## 色彩角色

| 角色 | 色值 |
| --- | --- |
| 主暖白背景 | `#FCFCFA` |
| 次暖白背景 | `#F7F7F4` |
| 结构线 | `#E7E5DE` |
| 黑色／主文字 | `#111111` |
| 次文字 | `#6B6B66` |
| 唯一主要焦点 | `#FBDD67` |
| 真实风险或例外 | `#EA580C` |
| 黑底次文字 | `#B4B4AE` |
| 黑底结构线 | `#4E4E49` |

黄色用于一个关键命题、连接路径、节点或活动阶段。橙色只用于真实的风险、
例外或矛盾，不与黄色争夺焦点。不要从参考图采样旧版米白、灰、黄。

## 文字

- 中文：Noto Sans SC；大标题可用 Light，正文用 Regular 或 Medium。
- 英文：Inter；标注、数据和元信息：Roboto Mono。
- 可选编辑点缀：标题最多一个简短拉丁词用 Tinos Italic。
- 不伪造中文斜体，不压缩字形，不用装饰字体。
- 维持大标题、正文、标注的清晰层级，确保手机尺寸仍可读；信息过多时
  拆开表达，避免不断缩小文字。标题行高约 1.05–1.15，正文约 1.25–1.4。
- 如需字体替代，应保证中文字形完整，并在生成的制作说明中记录替代。

## 明暗画布与节奏

暖白底承载多数解释与图解，主文字为黑色，次文字和结构线采用上述灰色。
黑底用于开场、叙事转折或收束等少量锚点，以暖白主文字和一个黄色焦点
形成对比。黑底画面保持简洁，不堆叠长段落、复杂表格或多卡片。
原演示文稿的黑页比例和页数不构成本视频的固定分镜要求。

黑底插画必须原生构成：暖白线稿、灰色结构网点、黄色路径或节点。
不可把白底图直接反相，不给黄色加发光；层级来自线宽、比例和留白。

## 插画、图形与限制

采用科学编辑线稿、规整结构网点、计算或研究符号、等距过程岛、黄色连接
弧线与节点。图形要解释一个关系，例如网络、流程、拓扑或反馈；避免只作
背景装饰。插画通常预留约 35–50% 干净区域给文字，细节在缩小后仍可辨认。
具体插画语言见 illustration-style.md。

图表扁平化、轴线克制、优先直接标注，不用三维图表。线性图标保持一致
线宽，不能用 emoji。颜色区别同时配合文字、形状或位置，保证对比可读。

禁止渐变、光晕、霓虹、玻璃效果、随机纸纹、装饰粒子、镜头光效、大投影
和通用企业三维人物。只允许等距插画内部极轻、短距离的落地阴影；标题、
卡片、图表不得加阴影。参考图中存在的旧纸纹不应复制到新画面。
